# ComfyUI FlowPack 0.0.6

- 统一导入安装页、展开后的资源详情及各类弹窗的按钮、圆角、颜色和交互状态；实例详情在软件中间显示，标签与顶部导航一致。
- 简化资源库为工作流、模型、节点三类；修复深色资源树文字及菜单样式，首页保留原有排版。
- 导出收敛为一份最终清单，工作流自动加入可确认依赖；用户取消的依赖保持取消，支持单独导出模型或节点包。
- 选择文件或目录后自动分析、匹配本地资源并生成安装计划；统一显示需要处理的问题，准备好后一次点击安装。
- App/Worker 协议升级为 6，统一 Python 依赖需求判断及执行前复核；Desktop 1.1.4 原生与接管已有目录布局具备已验证的文件及 Python 安装资格。未知版本、布局和不满足条件的计划继续显示原因。
- 增加独立 Desktop 配置范围、日志强度与保留周期设置，改善更新操作和后台任务状态。

Windows x64 自包含安装器，无需另装 .NET，安装器未签名。支持的 Desktop 资格及真实安装/工作流输出证据见项目文档。标准 Release 回归 367 通过、5 项按需专项跳过；此次实际 App 验证了页面导出、依赖取消保持、自动导入与本地复用预览。已有真实 Desktop 安装与输出证据保留为独立资格记录。

测试便携包、旧构建与大型隔离测试环境已从工作区清理；原便携/预览中的数据单独保留。正式交付为此版本安装器及 SHA256SUMS.txt。
