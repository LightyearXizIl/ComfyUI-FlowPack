# ComfyUI FlowPack 0.0.2

## 本版本内容

- 设置页显示作者 LightyearXizIl，支持打开和复制 GitHub 仓库链接，并可导出脱敏诊断摘要。
- 增加资源库持久化、主题偏好、Worker 本地 IPC、任务记录和经 SHA-256 校验的 staging 下载。
- 支持格式 1 资源包清单、`.cpack`/展开目录导入、原始工作流保留、草稿导入导出和不完整工作流包导出。
- 资源包、工作流、模型和节点列表支持本地筛选。

## 验证范围与限制

本版本将进行 Windows x64 自包含构建、自动化测试和安装器构建。真实 ComfyUI Desktop 绑定、部署写入、恢复、完整离线安装、试运行和安装生命周期尚未完成实机验证；安装操作因此保持禁用。安装包未进行代码签名。
