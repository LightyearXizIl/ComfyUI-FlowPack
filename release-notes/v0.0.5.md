# ComfyUI FlowPack 0.0.5

## 界面与功能入口

- 重绘主要页面。顶部按首页、我的资源、导入安装组织；任务和设置作为全局入口，打包工具归入资源库。
- 首页和资源库新增工作流、模型、节点文件夹入口。使用当前所选实例登记的真实路径，多个目录可选择；目录缺失时显示原因。
- 资源分类切换会选中对应页签；搜索、列表、操作区和空状态重新排版，改善最小窗口及深浅主题显示。
- 导入页左侧列表独立滚动，右侧固定目标、摘要和安装操作；导出使用独立预览窗口。

## 资源处理与更新

- 整合此前未公开发布的持久 Worker、任务暂停/继续/取消、在线依赖来源、原生 ZIP 导入导出、安装计划与恢复实现。
- 安装完成后重新检查实例与依赖；已存在资源按实际内容核对，避免把同名不同内容当作可复用。
- GitHub 更新接入下载、SHA-256 校验和独立更新引导。等待运行任务结束后交接安装器；校验失败阻止安装。
- 保留 API 执行图与 UI 工作流的原文，说明格式差异，不自动转换 JSON。

## 验证范围与限制

- Windows x64 自包含安装器，附 SHA256SUMS.txt；安装包未签名。
- 发布前运行锁定依赖还原、完整 Release 自动化测试、自包含发布及 Inno Setup 编译；构建证据见仓库 HANDOFF.md。
- 正式 ComfyUI Desktop 自动部署仍受版本、布局和能力验收门禁限制；目前生产资格表为空。本次发布不解除该门禁。
- 软件自身的实际页面下载、退出、安装升级、数据保留及重启完整流程仍待实机验收；测试通过不等于完整升级已验证。
- 完整系统多 DPI 交互、实际 Explorer 文件夹打开、干净机安装与卸载仍待验证。
