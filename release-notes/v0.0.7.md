# ComfyUI FlowPack 0.0.7

- 修正导入门禁：只有工作流，或只有工作流和节点包但没有模型时，只要没有文件完整性、目标冲突、解析或分析错误，仍可点击导入/安装。
- 将缺失或未匹配的模型、节点及输入依赖改为明确的提醒；真正阻塞安装的问题继续在执行前复核并阻止操作。
- 增加工作流单独导入、工作流加节点包但缺少模型的回归测试，并同步更新导入流程文档。

Windows x64 自包含安装器，无需另装 .NET，安装器未签名。正式构建会运行完整 Release 回归并生成 App、Worker 与安装器的 `SHA256SUMS.txt`；远端 GitHub Actions 与 Release 资产以发布证据为准。
