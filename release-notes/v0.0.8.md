# ComfyUI FlowPack 0.0.8

- 修复导出清单残留：取消资源后立即从最终清单移除；自动依赖显示来源，手动取消后不会被刷新或重新分析静默加回。
- 普通导出与旧草稿分离，避免扫描或重新启动后出现旧工作流。支持只导出所选工作流、模型或节点包。
- 勾选只刷新清单和数量，使用“更新导出预览”或导出前核算；未变化文件复用哈希，写 ZIP 时仍验证实际字节。预览大小明确表示资源总字节数。
- 实例发现补充已知本地安装目录、运行进程与自定义 Desktop 配置；首页“检测详情”展示配置目录、检查来源、跳过原因和错误。未登记候选保持只读。
- 隔离坏配置和跨配置重复实例 ID，避免有效实例被隐藏或扫描异常。App/Worker 协议升级为 7，需使用本版配套程序。

Windows x64 自包含安装器，无需另装 .NET，安装器未签名。正式构建运行完整 Release 回归，并提供 App、Worker 和安装器的 `SHA256SUMS.txt`。

升级建议使用旧版应用内更新，它会等待任务并安全退出后台。手动安装后若提示 Worker 协议不兼容，先在旧版确认任务结束，再重新启动 Windows 后打开新版；仅关闭旧界面不保证旧后台退出。

已验证包内 Worker 的单工作流 ZIP 与 manifest；WPF 窗口回归通过。外部点击验收因 computer-use 窗口绑定故障未完成，另一台电脑的实际实例发现仍需现场验证。本轮未重新运行真实 Desktop 安装或工作流推理。
