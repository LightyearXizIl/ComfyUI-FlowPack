# 设置中的日志功能

设置导航为：界面偏好 / Desktop 实例 / 资源库 / 日志 / 关于作者。资源库页面明确说明：保存 FlowPack 的清单、工作流记录、任务、下载暂存和恢复信息；ComfyUI 原有资源仍在实例目录。选择新库关联该目录，不会自动搬迁旧库。

日志页有记录强度、保留时间、一键清理、保存位置、打开文件夹和导出诊断摘要。清理按钮在小窗口首屏内可见，延续现有深浅模式和键盘焦点样式。诊断摘要从资源库移动到日志页。

- 关闭：停止新记录，仍清理超期日志。
- 仅错误：操作失败、连接错误、未处理异常。
- 标准（默认）：错误、启动/退出、更新检查、任务开始/完成。
- 详细：增加后台请求、页面切换和异常调用栈；不记录请求载荷、IPC 密钥或文件内容。
- 保留时间：7（默认）、10、15、30 天；立即保存生效。启动和运行期间每小时清理修改时间早于保留期限的文件，保留恰好处于期限边界的文件。

普通版配置和日志分别位于用户配置目录的 logging.json / Logs；便携和实时预览版位于 Data/Preferences/logging.json / Data/Logs。按 UTC 日期写入 flowpack-yyyy-MM-dd.jsonl。仅删除日志目录中符合该命名规则的普通文件，其他文件、资源库、任务和设置保留；正在记录时清理后仍可生成新日志。

ApplicationLog 控制强度、保存、清理及写入失败处理；ShellViewModel 和 WorkerLibraryClient 记录前台操作/请求与任务结果，应用记录 UI/后台未处理异常。日志不可写时不阻断应用业务。日志属于应用运行记录，不能代替 ComfyUI 自身的完整控制台输出。

验证：Release 全量 315 通过、5 专项跳过、0 失败；UI 布局调整后单独复验通过。覆盖四种强度、四种期限及边界、关闭模式清理、配置恢复、坏配置、写入失败、一键清理范围。深浅主题 1280/960 DIP 设置截图与结果在 artifacts/acceptance/logging-settings-20261005/。真实便携窗口五项导航、选择仅错误/15天写入配置、一键清理 1→0 个日志、保留资源库数据库通过，native-logging.json 记录结果。实时预览保存 XAML 后自动编译重启通过。
