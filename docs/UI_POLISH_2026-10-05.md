## 当前设置页：左侧导航与独立内容

按用户补充要求，设置页拆成四项左侧导航：**界面偏好 / Desktop 实例 / 资源库 / 关于作者**。右侧只显示选中的分区，不再把所有设置堆叠在同一长页中。使用 WPF TabControl，保留原生页签键盘与辅助功能语义；离开设置后返回时保留本次会话的选中项。

“关于作者”展示产品 Logo、作者、版本和完整的可点击 GitHub 仓库地址，并保留复制链接功能。检查更新和下载更新统一放在该页，没有独立更新导航。资源库页保留目录选择和诊断导出。外观保存、仓库链接和诊断反馈按功能独立，避免复制链接后提示出现在界面偏好里，也不再显示已经移除的主题预览说明。

本次 Release 全量测试 **299 通过 / 5 专项跳过 / 0 失败**，`git diff --check` 通过。设置专项遍历四个分区、深浅主题及 1280×800 / 960×640 DIP，核对更新与资源库操作的归属、GitHub 链接命令和地址、返回选中状态以及最小窗口更新按钮可见性。完成两轮批量截图检查。证据位于 `artifacts/acceptance/settings-navigation-20261005/full-final.trx` 和 `artifacts/acceptance/settings-navigation-20261005/final/`；截图是 WPF 测试夹具。没有重建安装器、安装、提交或发布。
