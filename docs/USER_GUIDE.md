# FlowPack 使用指南

本指南对应当前工作区的简化界面，可能与旧便携包或已发布安装器不同。固定版本测试包及验证范围以[当前交接状态](PROJECT_STATUS.md)为准。

FlowPack 用于查看 Windows x64 ComfyUI Desktop 实例中的工作流、模型和节点包，分析依赖，并在电脑之间转移选中的资源。安装是否可用由所选实例的 Desktop 版本、目录布局、所需 Python 能力及文件检查结果决定；条件不满足时，页面说明原因。

## 先选择启动方式

| 方式 | 如何打开 | 代码修改后是否更新 | 数据保存位置 |
|---|---|---|---|
| 便携测试包 | 完整解压 ZIP，双击 `Open-FlowPack.cmd` | 不会，内容固定为打包时版本 | 解压目录中的 `Data` |
| 源码实时预览 | 在源码根目录双击 `实时预览.cmd`，需要本机 .NET SDK | 保存产品源码后自动编译，成功后重启真实 WPF 窗口 | 源码下的 `artifacts/live-preview/Data` |
| 已安装版 | 从应用入口启动 | 通过“设置 → 关于作者”检查发布版本 | 用户配置目录和所关联的 FlowPack 资源库 |

便携包已包含运行时，无需安装 .NET。不要在压缩包内直接运行程序；移动便携包时，连同 `App`、`Data` 等内容一起移动。

实时预览通过重新编译并重启窗口更新界面。重启会重置当前页面和未保存的操作，并中断预览中的任务。测试大文件导出等长任务时，使用便携包或暂停修改源码。`停止实时预览.cmd` 会停止监视器和它启动的预览进程；只关闭窗口不会停止监视器。更多说明见[便携测试与实时预览](PORTABLE_PREVIEW.md)。

## 首页：确认实例和状态

1. 打开软件，等待实例检测与扫描。若发现多个实例，在窗口右上方选择本次要查看或操作的实例。
2. 没有找到目标时，使用“重新扫描”或“关联目录”。手动关联不会搬迁原有资源；关联普通 ComfyUI 资源目录时，可能仅提供检测和导出能力。
3. 查看“当前实例”中的名称、ComfyUI Core 和 Desktop 版本。不能确认的版本显示“未确认”。点击“版本详情”打开居中弹窗，分别查看 Desktop、磁盘 Core、运行 Core 和目录布局；弹窗中的“资源目录”标签可查看完整路径。
4. 点击“资源目录”直接打开目录弹窗，每个目录提供“复制”和“打开”。文件夹按钮有多个位置时，弹出名称与路径分行的菜单；“查看全部资源目录”进入同一弹窗。
5. 右侧“当前状态”显示扫描结果、资源数量和必要提示。点击“查看详情”打开按提示类别分组的居中弹窗，不再展开挤占首页。内容只在弹窗中滚动；点击“关闭”、按 Esc 或点击弹窗外的遮罩回到原页面。弹窗打开期间背景操作不可用。

弹窗标签与顶部导航一致，使用透明底与选中下划线；弹窗中的关闭、复制、打开等按钮沿用首页白底黑字圆角样式。提示窗口在软件中间显示，长说明独立滚动，Enter 或 Esc 可关闭。

文件夹直达按钮只在首页显示。它们打开所选实例的实际目录；关联实例、打开目录和扫描本身不会把文件安装到 ComfyUI。

## 资源库：找资源、看依赖

主导航中的“资源库”只包含“工作流”“模型”“节点”三个分类。工作流、模型和节点按扫描到的实际目录组织；模型的共享或扩展目录另行标明。

- 在右上角按名称、类别或路径搜索。清空搜索可恢复全部匹配范围；被搜索隐藏的资源仍保留原有勾选。
- 点击资源名称查看右侧详情；勾选框决定实际导出选择。
- 选中工作流后，右侧列出依赖的模型和节点包、位置、可用情况及引用关系。
- 节点类型归在所属节点包下。迁移时选择节点包，内置节点无需迁移。
- 页脚显示已选数量。“清空选择”取消本次全部勾选；“导出所选”进入统一导出页。
- 资源列表为空时，先清空搜索，再回首页重新扫描并确认当前实例。

### “仅在磁盘发现的工作流”是什么意思？

软件先扫描磁盘，再尝试核对所选实例的前端工作流列表。只有运行实例、用户上下文和前端列表都核对成功，未出现在该列表中的工作流才进入页面底部的独立区域。

该标记只表示“磁盘存在、已核对的列表中没有”，不代表文件已删除，也不会自动删除文件。离线、实例不匹配、用户未确认或查询失败时，显示“尚未核对前端列表”，继续保留磁盘扫描结果；不会把查询失败当成空列表。索引文件和无法识别为工作流的 JSON 不作为正常工作流列出。

## 导出资源：选择、自动整理、导出

1. 在资源库中勾选要带走的工作流、模型或节点，点击页脚“导出所选”。首页“导出资源”进入同一流程；没有勾选时先打开工作流列表。
2. 软件自动分析勾选的工作流，加入能够唯一确认的依赖，并检查导出文件。缺失或有多个候选的依赖不会被猜测为某个文件。
3. 在“导出清单”核对并调整勾选。清单是唯一的最终选择；取消某项就不将它写入 ZIP。修改后自动更新计划，无需另外生成预览。
4. 需要查看包内路径、大小或旧草稿时，展开“导出详情与高级选项”。
5. 条件满足后点击“导出 ZIP…”，选择保存位置，等待全局进度条报告完成。

同一次资源选择中，每个工作流只自动补选一次依赖。你取消的依赖不会因更新计划、切换页面或返回资源库重新加入；需要恢复时点击“重新添加依赖”，它仅按当前仍勾选的工作流补选。清空选择或换实例后，需要重新选择资源。

“返回资源库”保留原来的分类、搜索和勾选状态。导出工作流时，该工作流文件默认在清单中；如果只想取依赖，可在清单中取消工作流文件。

### 示例：只给另一台电脑补节点

在“节点”分类中勾选需要的节点包，再点“导出所选”。如果需要借助工作流找出所需节点，可先勾选工作流进入导出，等待自动补选后，在同一清单中取消工作流、模型和其他不需要的资源。展开详情确认文件载荷位于 `custom_nodes/`，再导出 ZIP；包中同时包含 FlowPack 资源清单。

只导出模型时，在“模型”分类中直接勾选即可。未导出的缺失模型不会阻止只导出节点包；实际选中文件不可读、路径不安全或模型分片不完整等问题仍需处理。共享依赖会去重；自定义节点以节点包为单位导出，包含其配套文件。资源转移不等于目标电脑已具备相同 Python 环境，也不证明工作流已经能运行。

## 导入安装：所有来源使用同一入口

在“导入安装”页面使用“选择文件”“选择文件夹”，或一次拖入一个文件或文件夹。未选来源时只显示来源入口和折叠的导入记录。

支持识别 ZIP、ComfyUI 工作流 JSON、资源目录，以及旧 `.cpack`、`.cpack.json`、JSON 清单和展开后的旧包。软件会根据内容识别用途；任意 ZIP 或 JSON 并不保证能识别成可安装资源。

选择后，软件自动识别导入内容，默认勾选用途已确认的资源，匹配当前实例中的本地资源，分析工作流依赖并检查安装计划。页面不显示步骤编号，也不要求先手动点击分析。

- **导入内容**显示分类和大小。需要调整时展开“查看并调整资源”；用途不明确的项目会自动展开，可在“详情与用途”中确认目标相对路径。
- **需要处理**只在有问题时出现，汇集缺失依赖、未确认用途、文件冲突等阻止原因。旧在线清单如果只有来源说明、没有文件，也在这里补全；核对后手动下载，或选择已有本地文件。
- **安装到**默认使用当前实例，可在右侧更换。摘要显示新增文件、复用文件和所需空间；详细目标路径收在“安装计划详情”。
- 调整资源、补全文件或更换实例后会自动重新检查。“重新检查”用于再次核对；检查期间和有阻止原因时，“安装”不可用。
- 条件满足后，点击一次“安装”执行。需要停止所选 ComfyUI 或处理 Python 依赖时，以页面提示为准。

自动分析不会自动下载缺失模型、关闭 ComfyUI 或执行安装。导入识别、下载暂存和生成计划只是在准备资源；文件部署完成后，节点是否加载、工作流是否能运行仍需在目标 Desktop 中验证。旧包、历史记录和已有关联数据继续使用原有兼容流程。

页面底部“导入记录”保存来源记录。点击“重新核对”会重新读取来源并进入同一流程；来源已移动或删除时，需要重新选择文件或目录。历史记录不能当作原始文件的备份。

## 资源库与存储位置

| 位置 | 用途 | 选择或切换后的影响 |
|---|---|---|
| 主导航“资源库” | 浏览当前 ComfyUI 实例的工作流、模型和节点，选择导出内容 | 随所选实例与扫描结果变化 |
| 设置“存储位置” | 指定 FlowPack 保存清单、记录、任务、下载暂存及恢复信息的数据目录 | 关联该目录的数据，不会自动搬迁旧库或 ComfyUI 模型、节点 |

仅切换实例不会把资源复制到另一实例。仅选择 FlowPack 资源库目录也不会完成安装或资源迁移。

常见保存位置如下，手动关联过的资源库以设置页面显示的实际位置为准：

| 数据 | 普通版默认位置 | 便携版默认位置 |
|---|---|---|
| 界面、语言、日志等配置 | `%APPDATA%\ComfyUI FlowPack` | `Data/Preferences` |
| FlowPack 资源库 | `%LOCALAPPDATA%\ComfyUI FlowPack\Data` | `Data/Library` |
| 应用日志 | `%APPDATA%\ComfyUI FlowPack\Logs` | `Data/Logs` |

便携版手动关联外部目录后，该目录仍是独立的实际文件位置，不会随便携包一起搬走。已有资源库不可用时，软件会要求重新关联，不会建立空库替代旧记录。需要保留记录时，应保留原资源库和配置；不要用删除 `Data` 作为常规清理方式。

## 设置、日志与更新

设置左侧提供“界面偏好”“Desktop 实例”“存储位置”“日志”“关于作者”。界面偏好可选择跟随系统、浅色、深色和语言；外观与语言即时生效。资源树正文、展开箭头和选择状态随主题切换，深色正文为浅色、辅助说明为灰色。

“Desktop 实例”使用与首页一致的“重新扫描”“关联目录”；完整安装路径收在展开详情中。“存储位置”中的“关联目录”用于选择 FlowPack 数据目录，完整路径和存储说明可分别展开查看。

### 日志

在“设置 → 日志”选择记录强度和保留时间，修改后立即保存并生效。

| 强度 | 记录内容 |
|---|---|
| 关闭 | 停止写入新日志，已有日志仍按保留期限清理 |
| 仅错误 | 操作失败、连接错误和未处理异常 |
| 标准 | 启动、退出、更新检查、任务开始与完成，以及错误；默认值 |
| 详细 | 增加后台请求、页面切换和错误调用栈，适合排查问题 |

保留时间可选 7、10、15、30 天，默认 7 天。它表示保留最近所选天数的日志，并非每隔这些天清空一次；启动时及运行期间每小时检查超期文件。

“一键清理日志”只清理应用自己的日志文件，保留资源库、任务及资源文件。清理后，后续操作仍按当前强度记录。需要提供问题材料时，使用“打开日志文件夹”或“导出诊断摘要”；诊断摘要提供脱敏信息。

### 关于作者与软件更新

“设置 → 关于作者”显示当前 FlowPack 版本、[GitHub 仓库](https://github.com/LightyearXizIl/ComfyUI-FlowPack)及复制链接按钮。

更新使用同一个按钮：点击“检查更新”，发现可用版本后变为“下载更新”；再次点击才进入下载、校验和安装器交接。检查失败会显示原因，不应当作已经确认是最新版。

这里检查的是 GitHub 发布版本，不是本机源码变更。便携版点击下载更新也走正式安装器流程，不会把便携文件夹实时替换成当前源码。测试最新本地改动请使用重新生成的便携包或源码实时预览。

## 如何理解进度和失败提示

扫描、校验、解压、导出、安装与下载过程中，全局进度条跨页面显示。

- 有总量时显示**当前阶段百分比**。进入下一阶段后，百分比可能重新计数，不代表任务倒退。
- 总量未知时显示活动进度条、阶段名称及已处理数量（若有），没有固定总百分比。
- 只有任务允许取消时，取消按钮才可用。导航保持可用，可能冲突的操作会暂时禁用。
- 成功收尾后显示“操作完成”；失败显示“操作未完成”和原因。不要仅凭某个阶段达到 100% 判断文件已经导出或安装成功。

遇到问题时，先查看全局错误及首页详情，记录触发步骤、所选实例和相关来源，再从设置导出诊断摘要。涉及资源缺失时，保留原工作流及包内清单，避免仅凭截图判断依赖。
