# 弹窗风格统一 · 2026-10-05

## 实现

首页保留恢复后的 R4 排版，版本、目录和状态继续使用 R6 居中弹窗。弹窗标签与顶部导航共用 `NavigationHeader` 的颜色、字体、64 DIP 高度、留白与 3 DIP 选中下划线；取消独立黑色标签底块。只加粗标签标题，正文左对齐铺满内容区。

`StandardActionButton` 提取首页白底黑字按钮的现有规格：38 DIP 最小高度、14/9 DIP 内边距、共享控件圆角与相同悬停、按下、禁用及键盘焦点模板。首页及详情的关闭、复制、打开、复制完整记录，以及保留的旧导出预览按钮均引用此样式。此次仅提取首页样式，按钮顺序、位置和大小未改。

软件原有的六处提示框调用改为 `NoticeDialog`：居中于所属窗口，正文独立滚动，按钮常驻，Enter / Esc 关闭。窗口标题、错误正文、原有成功/失败行为保留。Windows 文件和文件夹选择器仍由系统提供。
