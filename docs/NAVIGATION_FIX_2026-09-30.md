# 首页与二级菜单修复

日期：2026-09-30。基于已发布的 0.0.5 源码增量修改。本记录对应本地源码，不代表安装器已更新。

## 路由与页面关系

| 入口 | 实际目标 |
|---|---|
| 首页 → 导入资源 | 导入安装 → 导入资源；支持选择文件或目录 |
| 首页 → 导出打包 | 我的资源 → 导出打包 |
| 工作流 / 模型 / 节点入口 | 我的资源 → 对应页签 |
| 打包页 → 选择工作流 / 模型 / 节点 | 对应资源页签；保留资源选择 |
| 已有资源包 / 旧清单详情 | 导入安装 → 已有资源包 |
| 首页查看后台任务 / 下载任务入口 | 打开全局右侧任务面板；保留当前页面 |

我的资源现在有“工作流 / 模型 / 节点 / 导出打包”四个页签；导入安装有“导入资源 / 已有资源包”两个页签。返回资源库会记忆上次页签，明确的分类入口总是切到对应分类。打包页隐藏无关的资源搜索和目录入口；导入页保留左侧独立滚动和右侧安装摘要。

进入共享打包页会清除此前分类独立导出的范围和过期预览，避免选了多个分类却沿用单分类导出。独立导出预览仍保留原分类范围。导出摘要分别显示工作流、模型和节点源码文件数，便于在保存前核对。

## 节点缺失仍需实际材料

用户截图显示导出根目录有 `models`、`workflows`、`flowpack-manifest.json`，没有可见的 `custom_nodes`；模型目录含 `diffusion_models`、`loras`、`text_encoders`。这些截图无法证明缺少的是哪些节点，也不能确认依赖识别、选择范围或允许部分导出是否造成缺失。

截图中的 `D:\下载\ComfyUI-resources` 在本机检查时不存在，限定搜索也未找到对应 ZIP 或清单，因此本轮没有读取实际清单和原工作流。需要当前资源包路径，或其中的 `flowpack-manifest.json` 与原工作流 JSON，才能对照节点类型、依赖分析结果和 ZIP 实际内容定位。ComfyUI 内置节点无需随包携带；自定义节点源码是否应纳入必须根据原工作流和清单确认。
