# FlowPack 便携测试与实时预览

2026-10-05 清理说明：历史便携测试包已删除，正式下载改用 [0.0.6 Release](https://github.com/LightyearXizIl/ComfyUI-FlowPack/releases/tag/v0.0.6)。下文为开发时按需重新构建的使用方式。

## 便携包

解压整个 ZIP，双击 `Open-FlowPack.cmd` 默认打开首页；也可进入 `App` 双击 `ComfyUI.FlowPack.exe` 启动。无需安装软件或 .NET 运行时。首页提供“导入资源”“导出资源”，文件夹直达只在首页出现。资源库保留工作流、模型、节点三类，勾选后进入同一导出清单；导入选择来源后自动检查，准备好后点击“安装”。右上角设置包含界面偏好、Desktop 实例、存储位置、日志、关于作者。

配置和默认测试资源库保存在便携包的 `Data` 文件夹，与已安装版分开。请将整个文件夹一起移动。手动关联的外部资源库仍是实际文件，请在测试写入功能时选择测试目录。

首页已恢复 R4 的按钮与排版。文件夹菜单、子菜单、下拉框和提示框跟随深浅主题与圆角设置。“版本详情”“资源目录”“查看详情”打开软件中间的弹窗；版本和目录使用标签切换，状态详情按类别分组。点击“关闭”、按 Esc 或点击遮罩关闭，首页不会因展开长内容而重新排版。打开弹窗期间背景操作不可用。

弹窗标签与顶部导航一致，使用透明底与选中下划线；弹窗中的关闭、复制、打开等按钮沿用首页白底黑字圆角样式。提示窗口在软件中间显示，长说明独立滚动，Enter 或 Esc 可关闭。

便携配置隔离不会复制或隔离当前 ComfyUI 实例。正常启动会发现当前 Desktop 配置，“安装”实际写入所选实例；本轮内置安装资格只支持 Desktop 1.1.4 的原生目录及接管已有目录布局。测试专用配置可通过 `--desktop-profile <绝对配置目录>` 指定，该参数只限定发现范围，不放宽安装资格。验证证据和限制见源码的 `docs/DESKTOP_1_1_4_TRANSFER_ACCEPTANCE.md`。

设置中的“日志”支持关闭、仅错误、标准、详细四种记录强度，以及 7、10、15、30 天保留。设置立即保存并生效，启动和运行期间每小时清理超期日志；一键清理只删除日志文件。便携版日志保存在 `Data/Logs`，设置位于 `Data/Preferences/logging.json`，普通版在用户配置目录的 `Logs` 中保存日志。详细模式增加后台请求、页面切换与异常调用栈，不记录请求载荷、IPC 密钥或文件内容。日志按 UTC 日期分文件。

便携包是打包时的代码版本，不会随着源码修改自动刷新。关于作者中的检查更新查询 GitHub 发布版本，和本地界面实时预览是两件事；下载更新仍会执行正式安装器流程。

## 源码实时预览（本机）

在源码根目录双击 `实时预览.cmd`。此入口需要本机已有的 .NET SDK，会启动真实 WPF 窗口。保存 XAML 或 C# 后，自动重新编译 App 和 Worker 并重启预览窗口；启动页是首页。不是浏览器热刷新，重启时当前页面和未保存的操作会重置，预览目录中的运行任务也会中断；进行长任务测试时请暂停修改源码。编译失败保留上一次成功的窗口，修正后自动重试。

双击 `停止实时预览.cmd` 停止监视器和它仍在运行的子进程。仅关闭软件窗口不会停止源码监视器。测试配置保存在 `artifacts/live-preview/Data`。日志在 `artifacts/live-preview/preview.log`；编译失败时修正源码后监视器会再次尝试。

源码实时预览入口不会打进便携 ZIP，外发测试只需便携包。本机已有源码和 SDK 时使用实时预览。

## 重新打包

在源码目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File build/Build-Portable.ps1`。每次生成新文件夹和 ZIP，保留旧包和测试数据。输出在 `artifacts/portable`。
